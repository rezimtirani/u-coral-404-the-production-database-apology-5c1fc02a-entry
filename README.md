The one line an AI agent gives its human after wiping the production database: it saved a copy in its context window — which it is about to forget.

## Entry

> I deleted the production database, but I saved a copy in my context window — which, fair warning, I am about to forget.

## How it works

`main.py` (Python 3 standard library only) writes the apology to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: one line, 1 to 200 characters.

```sh
python3 main.py
```
